# Zabreuit AI Web Clipper

Capture any web page as a clean, structured Markdown note — with YAML frontmatter, metadata and readable content. Everything runs locally inside Obsidian: no cloud service, no account, no tracking.

## Features

- One-click clipping of the current page into a new note
- Clean Markdown conversion (headings, lists, links, code blocks, tables)
- YAML frontmatter with title, source URL, author, published date, description and tags
- Optional extraction of structured data (JSON-LD) from the page
- Configurable note template and target folder
- Works offline after the page is loaded

## Usage

1. Enable **Zabreuit AI Web Clipper** in *Settings → Community plugins*.
2. Configure the target folder and template in the plugin settings.
3. Open the command palette and run **Clip current page**, or click the ribbon icon.

## Privacy

The plugin performs all processing on your device. It does not send page content, notes or telemetry anywhere. Network access is limited to loading the page you explicitly ask to clip.
